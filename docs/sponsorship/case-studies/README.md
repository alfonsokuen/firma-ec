# Casos de uso de sponsors

Historias de organizaciones que patrocinan firmar.ec y cómo lo usan.

Para publicar un nuevo caso:

1. Copia [`_template.md`](./_template.md) a `nombre-organizacion.md`.
2. Complétalo con datos reales y métricas concretas.
3. **Obtén la aprobación escrita del sponsor** antes de publicar.
4. Agrega el logo en `assets/sponsors/[tier]/` (SVG vectorial).
5. Enlaza el caso desde la tabla de abajo.
