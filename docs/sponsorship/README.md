# Programa de Sponsorship — firmar.ec

## ¿Por qué patrocinar firmar.ec?

firmar.ec es la **alternativa open-source ecuatoriana** para firma
electrónica de documentos PDF. A diferencia de soluciones
propietarias:

- ✅ **Tu `.p12` nunca sale del navegador** (WebCrypto API)
- ✅ **SLSA Level 3** de supply chain security
- ✅ **Sigstore Cosign + Rekor Transparency Log**
- ✅ **Reproducible builds** verificables públicamente
- ✅ **AGPL-3.0** — sin vendor lock-in
- ✅ **PAdES-LTV** con TSA integrada (roadmap)
- ✅ **Compatible con Quipux** (roadmap)
- ✅ **Multi-firmante** vía Evolution API + BullMQ (roadmap)

## Lo que financian los sponsors

- Desarrollo de features prioritarios (PAdES-LTV, TSA, Quipux)
- Auditorías de seguridad independientes
- Infraestructura de CI/CD y SLSA
- Documentación y traducciones
- Soporte comunitario y triage de issues
- Hosting de demos y entornos de prueba

## Forma de pago — directa, sin intermediarios

El aporte se realiza por **transferencia bancaria directa** a
**IDKManager Cía. Ltda.**, con su respectiva **factura SRI** (IVA 15%
para Ecuador; exportación de servicios sin IVA para el exterior).

No usamos plataformas que retengan fondos ni cobren comisiones sobre tu
aporte: el 100% llega directo al proyecto.

1. Escríbenos a **sponsors@firmar.ec** indicando el tier.
2. Te enviamos los datos de la cuenta y la proforma.
3. Realizas la transferencia (mensual o anual).
4. Emitimos la factura SRI y activamos tus beneficios.
